# Faculty Resource Hub MVP

A specialized Faculty Repository System built to centralize academic, administrative, and technical documentation. Designed exclusively for teacher usage, this lightweight MVP provides a high-speed, easily searchable dashboard to share and discover critical resources without the clutter of a broader school management tool.


## 🚀 Features
* **Real-Time Search & Filtering:** Instantly filter resources by title, keyword, or specific categories (Syllabus, Policy, Tooling, Research).
* **Dynamic Resource Submission:** An interactive "Add Resource" modal that updates the repository grid instantly using React state, requiring no page reloads.
* **Responsive Design:** A clean, accessible interface built with Tailwind CSS, ensuring usability across desktop and mobile devices.

## 💻 Tech Stack
* **Framework:** Next.js (App Router)
* **UI Library:** React
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
